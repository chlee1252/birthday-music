# 발매일 카탈로그 초기 검증 — 2026-10-26

## 실제 수집 결과

로컬 PostgreSQL 14에 실제 Apple iTunes / 멜론 응답을 정규화해 저장했다. 이 기록 시점에는 Supabase 로그인이 완료되지 않아 클라우드 DB로의 이전은 미완료다.

- 가수/차트 크레딧 102개 (동일 이름의 개인 생일을 추정하지 않음)
- 앨범 메타데이터 758개 (모든 앨범의 곡 수집이 끝났다는 의미는 아님)
- 곡명+가수명 소문자 기준 서로 다른 조합 1,007개
- 공급처/앨범판별 곡 레코드 1,427개
- 일 단위 발매일이 있는 레코드 1,415개
- 수집 대기 920건, 실패 후 재시도 대기 1건 (`NO_TRACKS_RETURNED`)
- 테이블·인덱스·TOAST를 합한 실제 용량 2,433,024바이트 (약 2.4MB)
- 음악 파일, 이미지 원본, 외부 API 원문은 저장하지 않았다. 커버 URL과 출처 링크만 보관한다.

## 검색 확인

로컬 프로덕션 빌드의 `/api/section`을 순차 호출한 관측값이다. 외부 네트워크를 사용하는 전체 페이지 로딩 속도나 Supabase 배포 성능을 의미하지 않는다.

| 날짜/범위 | 결과 | 섹션 응답 시간 |
|---|---|---:|
| 1995-01-24 / 한국곡 / 정확한 날짜 | 김건모 — 잘못된 만남 | 79ms |
| 2014-10-27 / 팝송 / 정확한 날짜 | Taylor Swift — Blank Space 등 10곡 | 6ms |
| 1995-10-27 / 팝송 / 다른 해 같은 월일 | Mariah Carey / Taylor Swift 등 10곡 | 4ms |

브라우저에서 2014-10-27 팝송 결과의 앨범 커버, 발매일, YouTube·Apple Music 링크와 더보기 표시를 확인했다.

## 검증 범위와 남은 연결

- 자동 테스트 66개, Next.js 프로덕션 빌드 통과.
- 실제 PostgreSQL에서 정확한 날짜·월일·윤년·지역 분리, 부분 날짜 배제, 중복 저장 방지, 잘못된 쓰기 롤백, 가수 생일 보존, 작업 중복 실행 방지, RLS 설정 확인.
- 로컬의 별도 DB로 이전 스크립트를 실행해 한국 시간대에서 날짜가 하루 밀리지 않는 것도 확인했다.
- 이름이 겹치는 Adele / Michael Jackson / Madonna와 악센트 표기가 있는 Céline Dion은 공식 Apple Music 아티스트 페이지에서 ID를 확인했다. 실제 곡·발매일은 API에서 수집한다.
- 단일 앨범의 곡 목록을 받지 못한 작업은 성공으로 처리하지 않고 재시도 대상으로 남겼다.
- Supabase 무료 프로젝트 연결, 실제 DB 이전, Vercel `MUSIC_DATABASE_URL` 설정, 클라우드 연결 후 검증이 남아 있다.
- 정기 수집은 인증된 서버 경로와 CLI를 준비했으며, Supabase 연결 전에는 스케줄을 등록하지 않는다.
