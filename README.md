# 그날의 트랙

Next.js App Router SSR / React. 생일과 연결되는 한국 음악과 팝송을 실제 데이터에서 찾는 모바일 웹.

## 실행
Node 20.9 이상. `npm install`, `npm run build`, `npm start`.
http://127.0.0.1:4173 에서 테스트. 개발은 `npm run dev`.

## 화면 순서
1. 생년월일과 같은 날 발매된 앨범의 대표곡
2. 다른 연도지만 월·일이 같은 앨범의 대표곡
3. 생일의 월·일이 같은 가수 목록 → 가수 클릭 시 해당 가수의 곡
4. 생일 연도 / 10년 전 / 20년 전 인기곡

각 섹션에 한국 노래/팝송 칩을 제공하며 기본은 한국 노래. 선택은 URL의 카테고리별 파라미터로 독립 유지한다. 처음 3곡, 더보기로 최대 10곡. 생일 가수는 처음 3명, 더보기로 나머지 가수를 표시하며 가수 이름을 누르면 미리 받은 곡 목록을 펼친다. 펼치면 접기 버튼은 추가 곡 뒤 최하단에 위치한다. 일치하는 결과가 적으면 임의로 채우지 않는다. 실제 멜론 앨범 커버와 YouTube 검색 링크, 곡 정보·생일/발매 출처 링크 제공. 커버 실패 시 음표 대체.

## 데이터
- Wikidata: 국내 가수의 생일, 한국 아티스트의 발매 기록. 일 단위 정밀도까지 있는 날짜만 허용.
- MusicBrainz: 생일 당일의 국내 한국어 공식 발매 기록 보강.
- 멜론: 앨범 대표곡·발매일·커버, 곡 검색, 가수 프로필 대조, 연도별 차트.
- 가수 별칭은 Wikidata labels/aliases에서 조회. 같은 이름만으로 연결하지 않고 멜론 프로필의 전체 생년월일 및 아티스트 ID 검증.
- 실제 날짜 조회이며 정적 노래 목록을 결과로 대체하지 않음. API 키 불필요.
- 서버에서 모든 카테고리의 한국 노래·팝송을 병렬 조회하고 완료 후 한 번에 표시. 칩은 이미 받은 결과를 클라이언트에서 전환하며 추가 서버 요청을 하지 않는다. 첫 검색 중에는 전체 화면 로딩 표시. 실패한 결과의 다시 찾기는 선택 카테고리·장르만 요청하고 그 영역에만 로딩바를 표시한다.
- 팝송 발매는 Apple iTunes Search API를 우선 사용하고, 한국 노래는 멜론 조회 실패 시 Apple로 보완하며 가수·앨범·발매일을 대조한다. 역사 차트를 일반 검색 결과로 대체하지 않는다.

## 범위와 검증
검색 범위가 모든 곡을 포함하지는 않는다. 생일 발매는 수록 앨범 기준이며 최초 싱글 발매일과 다를 수 있다. 생일이 같은 가수의 그룹 곡 전체는 자동 포함하지 않는다. 연도별 차트는 1955년 이전과 올해 미지원.

`npm test`: 날짜·윤년·정확한 날짜/월일 구분, 별칭 매칭, 앨범/곡/생일 파싱, 동명이인 배제, 소스 장애 구분 등.
`npm run build`: 전체 테스트 및 프로덕션 빌드.

공개 멜론 HTML 파싱과 Wikidata/MusicBrainz에 의존하므로 데이터 누락·조회 지연·제공처 구조 변경이 있을 수 있다. 결과가 없을 때와 조회 실패를 구분해서 표시한다.

## 간결한 UI와 팝송
곡 설명과 출처는 정보 메뉴에 접고, 빈 결과는 Lucide 음표/검색 아이콘과 한 문장으로 표시. 조회 장애는 별도 연결 아이콘 표시.
생일 연결의 팝송은 미국·영국·캐나다·호주·아일랜드·뉴질랜드 아티스트 중 Wikidata에 널리 등재된 후보를 조회하며, 곡 자체의 멜론 역대 POP 차트 등재 또는 Wikidata 음악 곡/싱글 항목의 10개 이상 사이트 등재를 검증한다. 등재 수는 인지도의 대리 지표이며 실시간 인기 순위는 아니다. 재발매 앨범에 담긴 예전 히트곡도 확인할 수 있도록 역대 차트를 캐시한다. MusicBrainz 최초 발매 검색으로 팝송 당일 후보를 보강하되 실제 일 단위 날짜가 일치하는 기록만 쓴다. 모든 외국곡을 포함하는 것은 아니다.

## Vercel 배포
저장소 루트를 Next.js 프로젝트로 가져온다. API 키 없이 실행 가능. 빌드 명령 `npm run build`는 테스트를 포함한다. SSR 최대 실행 시간은 120초. 외부 제공처 장애 또는 해외 리전 접근 조건에 따라 결과가 달라질 수 있다. 실행 리전은 서울(icn1). 성공한 원천 응답·차트·전체 검색은 Next Data Cache에 최대 24시간 보관한다. 장애가 섞인 결과는 공유 캐시에 저장하지 않는다. 요청 제한과 진행 중 요청 병합은 인스턴스별이며 규모 확장 시 공용 제한기가 필요하다.
